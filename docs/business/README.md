## Как использовать

1. Перед стратегическим решением (цены, выход на рынок, инвестор) читать `01`, затем раздел 14 «что показать инвестору и чего не хватает».
2. Перед изменением кода читать в `02` разделы «что нельзя ломать» и «что может сделать хуже».
3. Перед работой с интерфейсом читать `DESIGN.md`, затем `03`.
4. Числа в разделе 8 плана — модель с явными формулами, а не прогноз. Подставьте свои допущения и пересчитайте.
5. Пакет не копирует секреты, значения `.env`, содержимое `data/` и `.secrets/`. Не добавляйте их при правках.
