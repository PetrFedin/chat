# ChatX · Graphite Warm v2

Документ описывает текущую систему и согласованную эволюцию. Метки: **[код]** - значение уже есть в `public/*.css`; **[новое]** - предложение, в код ещё не внесено и требует проверки (раздел 7 `docs/business/03-design-and-ui-analysis.md`). Значение из прежнего эталона, не совпадающее с кодом, исправлено: шкала радиусов в коде 12/16/22/28, а не 6/10/14.

## 1. Visual Theme & Atmosphere

Спокойный рабочий инструмент: графит, много воздуха, почти плоско, тёплый земляной акцент для выделенного. Чёрная версия (#050505) и светлая (#f4f4f2) - решение владельца, сохраняются. Один смысл на экран, детали по запросу. Сообщения без пузырей, плотный список бесед. Цвет почти монохромный; цвет только в метках, статусах и акценте.

Метки room-*: светлая ≥4,2, тёмная ≥4,7 (на surface-3 светлой channel 4,17 - только для иконки или с подписью).

Правила: цвет никогда не единственный носитель смысла (рядом слово или иконка). Не более трёх цветовых меток на экран без легенды. Цвет метки задаётся только парой `--label-ink` + `--label-wash` (neutral, red, amber, green, teal, blue, violet, grey). Новые цвета - только токеном.

## 3. Typography Rules

- Семейство: одно, `--font-sans` [новое: единый токен вместо двух разных стеков]. Inter упомянут в стеке, но `@font-face` в коде нет; либо положить Inter в каталог приложения (`CSP default-src 'self'` разрешает), либо перестать заявлять. Внешних CDN нет и быть не должно.
- Шкала [код, защищена тестом]: 11, 13, 15, 16, 17, 21, 27 px; вес 400, 600, 700, 800. Минимум 11 px; 10,5 px - устраняется [новое]. Информационный мелкий текст на телефоне - 12 px где место позволяет.
- Роли: display 27 / 800; heading 21 / 700, межбуквенный -.025em; title 17; сообщение 15 / 400, интерлиньяж 1,43; поле ввода 16 (не вызывает масштабирование на iOS); вторичный 13; подпись 11 (время, метки). Капс 11 px с разрядкой - только для разделителей.
- Числа в таблицах, счётчиках, времени: `font-variant-numeric: tabular-nums`.
- Моноширинный - для кода и идентификаторов.

Сетка 4/8/12/16/24. Радиусы [код]: r1 12 (кнопки, поля, чипы), r2 16 (карточки списков, строки), r3 22 (панели, диалоги, карточки задач), r4 28 (крупные листы), pill 999 (бейджи, чипы, точки). ## 6. Depth & Elevation

Почти плоско. Уровни: 0 - фон; 1 - поверхности с линией; 2 - всплывающие панели с одной тенью `--shadow`. Цветные боковые полосы `inset 3px 0 0` для статуса задачи (просрочка danger, успех success, внимание warm). `backdrop-filter` ограничить шапками и панелями звонков (дорого на слабых устройствах, замеров нет). Тени светлой темы заметно мягче.

## 7. Do's and Don'ts

Можно:
- брать цвет только из токенов; для текста в светлой теме - *-ink;
- вместе с каждым новым компонентом добавлять пару правил для светлой темы;
- держать фокус видимым в обеих темах (2 px, отступ 2);
- ставить подпись или иконку рядом с цветом статуса;
- уважать `prefers-reduced-motion`.

Нельзя:
- вводить новые hex-литералы, радиусы вне шкалы, кегли вне шкалы, текст мельче 11 px;
- ставить warm/danger/success/warning как цвет текста в светлой теме;
- яркие градиенты, неон, цветные тени;
- больше одной primary-кнопки на экран;
- менять чёрную и белую базы (#050505, #f4f4f2) без решения владельца;
- подключать внешние CDN-шрифты и стили (CSP `default-src 'self'`).

## 8. Responsive Behavior

Телефон (≤560 px): один экран, нижняя навигация, сенсорные цели ≥40 px (цель 44), список и беседа - разные экраны с кнопкой «назад». Планшет (≈561–980): две панели. Монитор (≥981): панель бесед + беседа (+ детали). Существующие точки: 360, 520, 560, 700, 800, 860, 980; новые не добавлять, сводить к 560 / 980. Сенсорный режим `pointer:coarse` увеличивает цели; `hover:none` убирает hover-зависимые действия. Ландшафт при высоте ≤520: компактная шапка. Масштабирование страницы разрешено. Тема: выбирает человек (хранится), цвет `theme-color` меняется вместе с темой; отслеживание системной темы - проверить, прежде чем обещать.

## 9. Agent Prompt Guide

- Перед работой с интерфейсом прочти этот файл и `docs/business/03-design-and-ui-analysis.md`.
- Меняй оформление через токены из `:root` и `html[data-theme="light"]`; в новых правилах нет hex-литералов.
- Каждое новое правило проверь в обеих темах; текст акцентом в светлой теме - только `*-ink`.
- Не менять: базы #050505 / #f4f4f2, шкалы радиусов, кеглей, начертаний, видимый фокус, отмену движения при reduced-motion (защищены `test/design-system.test.js`).
- Перед сдачей: контраст AA для текста, 3:1 для границ интерактивных элементов, цели касания ≥40 (цель 44), текст ≥11 px, одна primary на экран, `aria-label` у иконочных кнопок.
- Тесты: `node --test` с отдельной тестовой базой (`POSTGRES_TEST_URL`); смотри `# skipped`, должно быть 0.
- Внедряй постепенно: токены -> один файл css за шаг -> сверка скриншотов в обеих темах -> набор тестов.
